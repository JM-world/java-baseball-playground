# 숫자야구게임 다시 구현

## 기능 요구 사항
### 1. 컴퓨터가 숫자를 생성하는 기능
 - [x] 컴퓨터는 1에서 9까지 서로 다른 임의의 수 3개를 생성
   - [x] 중복되지 않았는지 검증
   - [x] 길이가 3자리인지 검증
   - [x] 1부터 9사이의 수인지 검증
 - [x] '숫자를 입력해 주세요 : ' 문구 출력

### 2. 플레이어가 숫자를 입력하는 기능
 - [x] 플레이어는 3개의 숫자를 입력한다.
     - [x] 1부터 9까지의 3자리인지 검증
     - [x] 중복되지 않았는지 검증
 - [x] 입력한 숫자에 대한 결과를 출력

### 3. 결과에 대한 힌트를 얻는 기능
- [x] 같은 수가 같은 자리에 있으면 스트라이크
- [x] 다른 자리에 있으면 볼
- [x] 같은 수가 전혀 없으면 낫싱 (또는 포볼)

### 4. 이 같은 과정을 반복해서 플레이어가 3개의 숫자를 모두 맞히면 종료하는 기능
 - [x] 3스트라이크가 아닌 경우, 2-2번으로 돌아가서 반복한다.
 - [x] 3스트라이크인 경우 '3개의 숫자를 모두 맞히셨습니다! 게임 종료' 문구 출력

### 4. 게임을 종료한 후 게임을 다시 시작하거나 완전히 종료하는 기능
 - [x] '게임을 새로 시작하려면 1, 종료하려면 2를 입력하세요.' 문구 출력
 - [x] 플레이어는 1 또는 2를 입력한다.
   - [x] 1 또는 2인지 검증
 - [x] 1을 입력한 경우 새로 시작하므로 2-1로 돌아가서 반복한다.
 - [x] 2를 입력한 경우 출력없이 그대로 종료한다.

## 프로그래밍 요구 사항
 1. 자바 코드 컨벤션을 지키면서 프로그래밍한다. (Google Java Style Guide 원칙)
 2. 들여쓰기는 '2 spaces'가 아닌 '4 spaces'로 한다.
 3. indent(인덴트, 들여쓰기) depth를 2가 넘지 않도록 구현한다. 1까지만 허용한다.
 4. else 예약어를 쓰지 않는다.
 5. 모든 로직에 단위 테스트를 구현한다. 단, UI(System.out, System.in) 로직은 제외
 6. 핵심 로직을 구현하는 코드와 UI를 담당하는 로직을 구분한다.
 7. UI 로직을 InputView, ResultView와 같은 클래스를 추가해 분리한다.
 8. 3항 연산자를 쓰지 않는다.
 9. 함수(또는 메소드)가 한 가지 일만 하도록 최대한 작게 만들어라.
