# 숫자 야구 게임 (Baseball Game)

숫자야구 게임은 컴퓨터가 만든 3자리 수를 플레이어가 추측하는 게임이다.  
스트라이크, 볼, 낫싱 힌트를 통해 답을 맞추고, 3스트라이크가 되면 승리한다.  

#  기능 목록

### 1. 게임 시작
- 컴퓨터가 1~9까지 서로 다른 3개의 숫자를 랜덤으로 생성한다.

### 2. 사용자 입력
- 사용자가 3자리 숫자를 입력할 수 있도록 한다.

### 3. 입력값 검증
- 입력값이 3자리 숫자인지 검증한다.
- 중복된 숫자가 없는지 확인한다.
- 0이 포함되어 있지 않은지 확인한다.
- 숫자 외의 문자가 포함되어 있지 않은지 확인한다.

### 4. 숫자 비교
- 컴퓨터가 만든 숫자와 사용자의 숫자를 비교하여
    - 같은 자리/같은 숫자: 스트라이크
    - 다른 자리/같은 숫자: 볼
    - 전혀 일치하지 않으면 낫싱 결과를 반환한다.

### 5. 결과 출력
- 볼, 스트라이크, 낫싱 결과를 사용자에게 출력한다.

### 6. 게임 종료 및 재시작
- 3스트라이크가 되면 게임이 종료된다.
- 게임 종료 후, 1을 입력하면 새 게임 시작, 2를 입력하면 완전 종료한다.

# 개발 규칙

- 들여쓰기(indent) depth는 최대 1까지만 허용한다.
- else 예약어를 사용하지 않는다.
- switch/case 문을 사용하지 않는다.
- 3항 연산자(ternary operator)는 사용하지 않는다.
- 모든 핵심 로직에 단위 테스트를 작성한다. (입출력 제외)
- UI 로직은 별도의 InputView, ResultView 클래스로 분리한다.
- 메소드 하나는 한 가지 일만 하도록 작성한다.
